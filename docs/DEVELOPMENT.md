# 技术记录与历史验收

0.6.0 的日常界面已移除调试入口。输入验证、性能采样仍可通过启动参数使用，下文 0.5.x 的按钮描述为历史记录。主界面使用原生 WinForms 绘制，无持续动画或额外采样循环；核心浏览器、连点与时钟逻辑沿用已验证实现。

# 造梦工坊 Demo 0.5.3

Windows 10/11 x64 上的造梦西游3在线版实验客户端。入口使用 4399 官方页面，登录及存档仍由游戏服务器处理。

## 0.5.3 更新

- 默认通过 CEF `SetAccessibilityState(Disabled)` 关闭游戏网页的辅助技术接口，同时设置 `disable-renderer-accessibility` 阻止自动重新启用，避免外部控件查询触发浏览器主线程长停顿。侧栏的普通键鼠操作、快捷键和 WinForms 控件的辅助功能保留。
- 如需读屏软件读取网页，使用 `start-demo.cmd --enable-web-accessibility` 恢复网页辅助接口；可能重新出现本机观察到的查询开销。未禁用 Windows 或其他应用的辅助功能。
- 工具栏新增“性能采样”：当前页约 15 秒，记录窗口/浏览器队列延迟及插件/浏览器事件时序，结果存放于 `artifacts/demo/data/页面编号/performance`。正常运行不采样。日志不采集 Cookie、网页文字、截图或按键内容。
- 启动参数 `--performance-capture` 在启动约 20 秒后自动采样；诊断专用 `--performance-capture --performance-compare` 按启用/关闭网页辅助接口分别采样。对照模式会放开自动启用限制，结束后恢复 API 状态；正常使用需不带对照参数重新启动。采样时保持游戏在前台，点击采样后继续在游戏内操作。
- `scripts/analyze-performance.ps1 -Path <采样文件>` 输出概要。队列延迟是程序内部调度测量，插件绘制事件间隔也不等同于游戏逻辑 FPS 或完整键鼠延迟。

## 0.5.2 更新

- 所有游戏页面的 CEF 引擎启用 `no-proxy-server`，直接连接，不使用 Windows 系统代理或 PAC。重新启动应用后生效，不修改 Windows 的代理设置。
- 页面链接打开的外部默认浏览器仍按该浏览器自身的网络设置运行。本开关不改变 VPN/TUN 的系统路由。
- 参数依据：[Chromium 网络设置](https://new.chromium.org/developers/design-documents/network-settings/)。

## 0.5.1 更新

- 页面内点击的 HTTP/HTTPS 链接由 Windows 默认浏览器打开，不替换游戏页面。普通链接、`target="_blank"`、点击触发的 `window.open`、Ctrl+点击和鼠标中键均使用同一处理逻辑。
- 工具栏“进入游戏”“刷新”仍作用于当前游戏页；自动加载、登录表单提交及服务器重定向仍在内嵌页面处理。自动弹窗不启动外部浏览器，文件及自定义协议不交给系统执行。
- 集成测试使用真实 CEF 点击事件验证路由，记录外部启动请求以避免批量打开浏览器标签。

## 0.5 更新

- 全新浅色工作台：浅灰背景、白色面板、蓝色强调色；倍率改为 1× / 2× / 3× / 100× 四个按钮。
- 页面 A 常驻且保留声音；B–D 显示关闭按钮，创建时即静音。关闭当前页面返回 A；关闭后台页面保留当前页。关闭后的编号可以复用，缓存与登录资料保留。
- 键盘默认三行 **S、S、J**，间隔均为 **1 ms**，全部不启用。点击按键框后直接按下目标键；每行可删除，可新增至最多 32 行，移除上下移动与下拉选择。
- 键盘列表在全部页面间共享；F7 只执行当前页面，切页停止。运行中修改在下一次启动生效。
- 游戏倍率在全部页面间共享，新建页面自动采用当前倍率。F8 全部停止并恢复 1×。
- 新增页面 A 的 0～100% 音量滑杆，0% 静音。使用 Windows 音频会话控制 A 的浏览器/Flash 子进程声音，B–D 始终静音，不改变系统总音量。

## 0.4 更新

- 修复 F7 启动连点时短暂失焦：已获得焦点的浏览器/Flash 子窗口不再重复切换焦点；运行状态更新也不再禁用当前设置控件而触发焦点转移。
- 每行间隔支持 **1～60000 ms**，步进 1 ms。间隔仍指释放本行按键后到下一行按下前的等待；按住时间改为 `min(30 ms, 本行间隔)`，避免固定 30 ms 按住时间限制小间隔。
- 使用独立工作线程和可取消的 Windows 高精度可等待计时器；旧系统回退普通可等待计时器，并仅在循环期间请求 1 ms 定时精度。没有忙等循环。
- 运行中可以修改设置，修改在下一次 F7 启动时生效；当前循环继续使用启动时的配置副本。

## 0.3 历史更新（设置方式以 0.5 为准）

- 连点器改为键盘列表，每行包含“按键 / 间隔（毫秒）/ 是否启用”。鼠标连点和坐标采集暂时移除，普通鼠标操作照常可用。
- F7 开始或停止当前页的键盘循环；仅按从上到下的顺序执行启用行，最后一行结束后返回第一行。重新启动从第一条启用项开始。
- 间隔使用真实时间，不受游戏倍率影响；不同时按住多个自动按键。
- 支持新增、删除、上移、下移，最多 32 行。点击行中的任意设置选中该行，再用上下移动调整顺序。
- 各页面独立保留本次运行中的列表；切页停止原页的键盘循环。F8 停止全部页面、释放当前按键并恢复 1×。

## 0.2 更新

- 改为一个主窗口，左侧切换 A–D 页面；新建页面不再弹出另一个窗口。切页保留已加载的游戏、登录态和各页参数。
- 普通键鼠输入直接进入原生浏览器控件。移除 WPF/WinForms 混合承载；浏览器、Flash 与主界面分进程，控制指令使用异步命名管道。
- 启动后的默认 1× 不启用时钟 Hook；变速时的计时路径去掉逐次加锁和读取共享内存。切回 1× 后保留连续的时间偏移，使用轻量路径，避免时钟倒退。
- 切页立即停止原页面连点并释放按键；快速切页和 F8 与正在启动的连点之间也有状态保护。只在连点运行时提高 Windows 定时精度。
- 保留 GPU 渲染，并关闭内嵌进程被浏览器误判为后台时的降频。如特定显卡出现绘制问题，可用 `start-demo.cmd --software-rendering` 对比软件渲染。

## 直接运行

双击项目根目录的 `start-demo.cmd`，或运行 `artifacts/demo/ZmxyDemo.exe`。整个 `artifacts/demo` 目录需保持完整。

- **进入造梦西游3**：进入官方合集的“大闹天庭篇”直达页面 `https://www.4399.com/flash/zmhj.htm?g=3`。
- **＋ 新建同账号页面**：在当前窗口增加页面并继承当前 4399 登录态，最多四页。左侧点击“页面 A/B/C/D”切换。各页分别选择同一云存档。
- **关闭页面**：点击 B–D 右侧的 ×。A 不提供关闭入口。关闭前自行保存游戏，客户端不自动保存进度。
- **游戏变速**：全部页面统一选择 1、2、3、100 倍，默认 1 倍。游戏逻辑变速仍未做关卡内定量验收。
- **键盘连点**：按行设置按键、间隔和启用状态，列表由所有页面共用。默认 S、S、J / 1 ms / 全部未启用；点击输入框后直接按键，支持 A–Z、0–9、空格、方向键、Enter、Tab、Esc 及 F1–F6/F9–F12；F7/F8 保留为控制热键。输入框正在录入时，F7 不会启动连点。
- **游戏音量**：拖动 0～100% 滑杆控制页面 A，其他页面始终静音。声音来源是页面 A，即使切换到 B–D 也不改变来源；游戏自身仍可能在后台暂停。
- **F7**：开始或停止当前页面的键盘循环，所有行未启用时不会启动。默认需切回 Demo 才能用 F7 启动；勾选允许切换到其他应用后继续连点后可在后台启动。
- **F8**：停止所有页面连点、释放按键并恢复 1 倍速。切页始终停止原页面连点；切换到其他应用默认也停止，可手动勾选允许继续。
- **本地验证**：运行 `start-demo.cmd --test-page` 使用隔离的测试资料，或滚动左侧面板点击“输入验证”。验证页显示实际执行顺序、次数和按住数量，不需要游戏账号。
- 若 F7/F8 已被其他程序占用，底栏会显示提示，仍可点击对应按钮操作。
- 如果游戏画面右侧被裁切，请最大化窗口。游戏失去焦点后可能显示“点击继续”；这是游戏自身的暂停界面，切回后点击即可。
- “允许切换到其他应用后继续连点”只控制输入调度，不会取消游戏自身的失焦暂停逻辑。

## 小间隔调研与实测（2026-11-12）

**多玩连点器的最低间隔尚未核实。** 检索到的公开下载介绍没有提供可验证的官方最低值，也未取得可确认来源的原版程序进行测量。因此不把“最低 0 ms”或“最低 1 ms”作为已证实结论。本版按用户需要直接支持 1 ms 设置。

微软文档说明，`Task.Delay` 的短延时受系统时钟分辨率影响；因此本版不再用它调度键盘循环。`CREATE_WAITABLE_TIMER_HIGH_RESOLUTION` 从 Windows 10 1803 起支持，用于短间隔计时。设置值仍不是实时保证：线程调度、CEF 队列及游戏帧率都会影响实际响应。参考：[Task.Delay](https://learn.microsoft.com/en-us/dotnet/api/system.threading.tasks.task.delay)、[CreateWaitableTimerExW](https://learn.microsoft.com/en-us/windows/win32/api/synchapi/nf-synchapi-createwaitabletimerexw)。

本机短时验证结果如下。完整周期指一次按下到下一次按下，包含按住、释放后等待和调度开销；数值来自发送端 `Stopwatch` 时间戳，旧版 CEF 的事件时间戳粒度较粗，不用于判断毫秒级精度。

| 设置的释放后间隔 | 按住时间 | 实测平均完整周期 | 完整周期 P95 |
| --- | --- | --- | --- |
| 1 ms | 1 ms | 3.07 ms | 3.15 ms |
| 2 ms | 2 ms | 4.85 ms | 5.05 ms |
| 5 ms | 5 ms | 10.71 ms | 11.05 ms |
| 10 ms | 10 ms | 20.82 ms | 21.06 ms |

测试页面收到了这些输入，停止后没有遗留按住的键；这不代表 Flash 游戏会识别每次极短按键，也不代表每 1 ms 能触发一次游戏动作。测试明细见 `artifacts/demo/integration-test-results.json`。

**运行依赖**：仅提取 PPAPI DLL 不足以运行国区 Flash；缺少后台组件时游戏区会显示 “A required system component is not running properly, please repair Adobe Flash Player.” 用户明确同意后，本机已通过官网安装器安装 Flash PPAPI 34.0.0.384 和 Flash Helper Service，服务当前运行且设置为自动启动。项目没有修改 Flash 授权/组件检查。其他电脑仍需正常安装/修复官方运行依赖。

## 从源码构建

依赖：Windows x64、.NET Framework 4.8 运行时，准备 Flash 时需要 7-Zip。所有编译工具均下载到项目目录，不要求全局安装 SDK。

```powershell
./bootstrap.ps1 -Flash
./build.ps1 -Restore -Test
./start-demo.cmd
```

`bootstrap.ps1` 下载固定版本的 .NET SDK 10.0.404、Zig 0.13.0、MinHook 1.3.4，并核验哈希。`-Flash` 仅下载、提取和验证官方插件，不运行安装器；不会解决缺失系统服务的问题。

`build.ps1 -Test` 执行原生时钟/导航策略自测，结果写入 `artifacts/demo/self-test-results.json`。

旧版正在运行时可先用 `build.ps1 -Test -OutputDirectory artifacts/ui-preview` 构建独立预览包，避免覆盖已打开的程序文件。

运行 `artifacts/demo/ZmxyDemo.exe --integration-test` 可执行实际浏览器多页集成检查，结束后自动退出，结果写入 `integration-test-results.json`，退出码非零表示失败。测试使用独立的 `test-data`，不触碰正式账号资料。

正式页面日志位于 `artifacts/demo/data/A/logs` 至 `data/D/logs`；主界面异常写入 `data/shell-error.log`。历史日志保留，按时间判断最近一次错误。更新构建前先关闭 Demo。

## 实现

```text
一个 WinForms 主窗口（左侧页面切换、F7/F8）
  ├─ A / B / C / D 原生子窗口，各自独立 worker 进程
  │   ├─ CefSharp WinForms / Chromium 84 → 4399 官方网页
  │   ├─ 独立缓存和 Cookie；切页隐藏，不重新导航
  │   └─ 键盘列表 → 顺序调度 → CefSharp 按下/释放事件 → 当前网页 / Flash
  ├─ 私有异步命名管道 → 页面控制、登录态交接、释放输入
  └─ 每页独立共享内存 → 自有 PPAPI 子进程 → zmxy-speed.dll
```

- `src/ZmxyDemo`：界面、窗口生命周期、登录态传递、连点、共享控制和自测。
- `KeyboardSequenceEditor.cs` / `KeyboardStep.cs` / `InputRepeater.cs`：三列设置、按键和间隔验证、可取消的顺序循环；启动时复制配置，切页与停止通过同一生命周期锁释放当前键。
- `PreciseDelay.cs`：独立线程使用的可取消原生计时器；`BrowserFocus.cs`：检查浏览器及 Flash 子窗口焦点，避免启动时制造短暂失焦。
- `GameAudio.cs`：在独立线程枚举 Windows 音频会话，只修改本程序游戏 worker 及子进程的会话音量；追踪新音频流与输出设备变化，不修改系统或其他应用音量。音量 API 参考：[ISimpleAudioVolume](https://learn.microsoft.com/en-us/windows/win32/api/audioclient/nf-audioclient-isimpleaudiovolume-setmastervolume)。
- `src/ZmxySubprocess`：自定义 CEF 子进程；仅在 `--type=ppapi` 时加载变速模块。
- `native/speed.c`：MinHook 包装 `timeGetTime`、`GetTickCount`、`GetTickCount64`；不 Hook QPC，保留真实时间基准。父进程心跳失效时恢复正常倍率。不同游戏若用其他时间源，还需适配。
- `scripts/prepare-flash.ps1`：解包官方 Flash 安装包并验证最终 DLL 签名/哈希。
- 命名管道 ACL 仅允许当前 Windows 用户，使用随机名称；登录态交接只传 4399 域 Cookie，不导出密码，不写临时文件。
